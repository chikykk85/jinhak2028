# 2학년 진학 상담관리 — 설치 안내 (Firebase + GitHub Pages)

- **GitHub Pages**: 선생님들이 접속하는 웹 주소를 제공합니다.
- **Firebase**: 로그인과 데이터 저장을 맡습니다. 한 선생님이 저장하면 다른 선생님 화면에 바로 반영됩니다.

무료 요금제(Spark)로 충분합니다. 처음 설정은 30~40분 정도 걸립니다.

---

## 0. 준비물

| 파일 | 어디에 두나 |
|---|---|
| `index.html` | GitHub 저장소 |
| `firestore.rules` | Firebase 규칙에 붙여 넣기 (GitHub에 함께 올려도 됨) |
| `README.md` | GitHub 저장소 (이 안내문) |
| `학생명단_성적_업로드용.json` | ⚠️ **GitHub에 절대 올리지 마세요.** 부장 선생님 컴퓨터에만 보관 |

> GitHub Pages 저장소는 누구나 볼 수 있습니다. 그래서 학생 이름과 성적은 `index.html`에서 빼 두었습니다. 관리자가 로그인한 뒤 JSON 파일을 올리면 Firebase에만 저장됩니다.

---

## 1. Firebase 프로젝트 만들기

1. https://console.firebase.google.com 에 접속해 구글 계정으로 로그인합니다.
2. **프로젝트 만들기** → 이름 입력(예: `yubong-jinhak`) → Google 애널리틱스는 **사용 안 함** → 만들기.

## 2. 웹 앱 등록 → 설정값을 index.html에 붙여 넣기

1. 프로젝트 첫 화면에서 **웹(`</>`) 아이콘**을 누릅니다.
2. 앱 이름(예: `jinhak-web`)을 입력합니다. Firebase Hosting은 체크하지 않고 **앱 등록**을 누릅니다.
3. 화면에 나오는 `const firebaseConfig = { ... }` 안의 6줄을 복사합니다.
4. `index.html`을 메모장(또는 VS Code)으로 열고 `여기에_붙여넣기`라고 적힌 부분을 찾아 그대로 바꿉니다.

```js
const firebaseConfig = {
  apiKey: "AIza...",
  authDomain: "yubong-jinhak.firebaseapp.com",
  projectId: "yubong-jinhak",
  storageBucket: "yubong-jinhak.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcd..."
};
```

> 이 값은 공개되어도 괜찮습니다. 데이터 보호는 3·4단계의 로그인과 보안 규칙이 담당합니다.

## 3. 로그인(Authentication) 설정 — 계정 10개 만들기

1. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**를 누릅니다.
2. **로그인 방법** 탭에서 **이메일/비밀번호**를 사용 설정하고 저장합니다.
3. **사용자** 탭에서 **사용자 추가**를 눌러 아래 10개를 만듭니다.
   - 선생님은 이메일이 아니라 **이름**으로 로그인합니다. 이메일은 프로그램 내부용입니다.
   - 임시 비밀번호는 **6자리 이상**이어야 하고, **선생님마다 다르게** 정하세요. 첫 로그인 때 각자 새 비밀번호로 바꾸게 됩니다.

| 이름 | 역할 | 이메일 (그대로 입력) |
|---|---|---|
| 윤원석 | 2학년 부장(관리자) | `jinhak.admin@example.com` |
| 이준우 | 1반 담임 | `jinhak.class1@example.com` |
| 김혜경 | 2반 담임 | `jinhak.class2@example.com` |
| 정수현 | 3반 담임 | `jinhak.class3@example.com` |
| 최순학 | 4반 담임 | `jinhak.class4@example.com` |
| 박성훈 | 5반 담임 | `jinhak.class5@example.com` |
| 민선영 | 6반 담임 | `jinhak.class6@example.com` |
| 김효진 | 7반 담임 | `jinhak.class7@example.com` |
| 이헌종 | 8반 담임 | `jinhak.class8@example.com` |
| 이창호 | 9반 담임 | `jinhak.class9@example.com` |

> 담임이 바뀌면 `index.html`의 `TEACHER_DIRECTORY`에서 이름만 고치면 됩니다.

## 4. 데이터베이스(Firestore) 만들기 + 보안 규칙

1. 왼쪽 메뉴 **빌드 → Firestore Database → 데이터베이스 만들기**를 누릅니다.
2. 위치는 **asia-northeast3 (서울)** 을 고릅니다. 나중에 바꿀 수 없습니다.
3. **프로덕션 모드**로 시작합니다.
4. **규칙** 탭을 열고 기존 내용을 모두 지운 뒤, `firestore.rules` 내용을 통째로 붙여 넣고 **게시**합니다.

규칙이 하는 일:
- 담임은 **자기 반 학생만** 보고 저장할 수 있습니다. 다른 반 학생은 보이지도 않습니다.
- 관리자는 전체 학생을 보고, 학생 명단·성적을 올릴 수 있습니다.
- 로그인하지 않은 사람은 아무것도 볼 수 없습니다.

## 5. GitHub에 올려서 웹 주소 만들기

1. https://github.com 에서 **New repository**를 누릅니다.
   - 이름: 예) `jinhak` / **Public**
   - 무료 계정은 Public 저장소만 Pages를 쓸 수 있습니다. 학생 정보가 파일에 없으므로 Public이어도 괜찮습니다.
2. **Add file → Upload files**로 `index.html`, `firestore.rules`, `README.md`를 올리고 **Commit changes**를 누릅니다.
   - ⚠️ `학생명단_성적_업로드용.json`은 올리지 않습니다.
3. 저장소 **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 정하고 **Save**합니다.
4. 1~2분 뒤 위쪽에 주소가 나옵니다: `https://내아이디.github.io/jinhak/`

## 6. Firebase에 GitHub 주소 등록

Firebase 콘솔 → **Authentication → 설정 → 승인된 도메인 → 도메인 추가**에서 `내아이디.github.io`를 추가합니다.

## 7. 관리자 첫 로그인 → 학생 명단 올리기

1. 웹 주소에 접속해 **윤원석** + 임시 비밀번호로 로그인합니다.
2. 비밀번호 변경 창이 뜨면 새 비밀번호로 바꿉니다.
3. **📊 학급별 진행 통계** 탭 → **📂 학생 명단·성적 올리기 → JSON 파일 선택**에서 `학생명단_성적_업로드용.json`을 고릅니다.
4. "학생 208명 … 올렸습니다"가 나오면 끝입니다. 이때 담임 계정 정보도 함께 만들어집니다.

> 이 단계 전에는 담임 선생님이 로그인해도 "권한이 없습니다"라고 나옵니다. 꼭 관리자가 먼저 해 주세요.

## 8. 담임 선생님께 안내

- 웹 주소, 그리고 **본인 이름 + 임시 비밀번호**를 각자에게 따로 전달합니다. 단체방에 한꺼번에 올리지 마세요.
- 첫 로그인 때 새 비밀번호로 바꾸게 됩니다.
- 휴대폰에서도 같은 주소로 쓸 수 있습니다. 홈 화면에 추가해 두면 편합니다.
- 브라우저를 닫으면 자동으로 로그아웃됩니다. 학교 공용 PC 대비용입니다.

## 운영하면서

**비밀번호를 잊은 선생님이 있을 때**
1. Firebase 콘솔 → Authentication → 사용자에서 그 선생님 이메일을 삭제합니다.
2. **사용자 추가**로 같은 이메일, 새 임시 비밀번호를 만듭니다.
3. 프로그램 **🔑 교사 계정 현황** 탭에서 **변경 요구**를 누릅니다.

상담 기록은 그대로 남습니다.

**2학년 2학기 확정 성적이 나오면**
새 JSON 파일을 같은 방법으로 올리면 성적만 바뀝니다. 파일 만들기가 필요하면 요청해 주세요.
※ 현재 화면은 2학년 2학기를 항상 '예상'으로 표시합니다. 확정 성적으로 바꿀 때 표시도 함께 고쳐야 합니다.

**백업**
관리자 화면 **백업저장**으로 주기적으로(예: 매주) 파일을 내려받아 두세요. 학교 컴퓨터에 보관합니다.

**프로그램 수정**
GitHub 저장소에서 `index.html`을 새 파일로 교체(Upload files)하면 1~2분 뒤 반영됩니다. 이때 2단계의 `firebaseConfig` 값이 그대로 들어 있는지 확인하세요.

**동시에 수정할 때**
담임은 자기 반만 수정하므로 겹칠 일이 거의 없습니다. 관리자와 담임이 같은 학생을 동시에 작성하는 중에 상대가 먼저 저장하면 "다른 선생님이 이 학생의 기록을 수정했습니다" 알림이 뜹니다. 그 상태에서 저장하면 내 내용으로 덮어씁니다.

## 개인정보 관련

학생 성적과 진학 희망 정보는 개인정보입니다. 운영 전에 학교 개인정보 보호 담당자에게 외부 서비스(Google Firebase) 사용이 가능한지 확인해 주세요.
